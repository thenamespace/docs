Check availability before generating mint transaction parameters. Use the L1 or L2 method that matches the parent name's listing.

## Check availability on L1

Use `isL1SubnameAvailable` for a parent name listed on Ethereum mainnet:

```typescript
const isAvailable = await mintClient.isL1SubnameAvailable(
  'alice.example.eth',
);
```

## Check availability on L2

Use `isL2SubnameAvailable` with the target chain ID. This example checks Base:

```typescript
import { base } from 'viem/chains';

const isAvailable = await mintClient.isL2SubnameAvailable(
  'alice.example.eth',
  base.id,
);
```
