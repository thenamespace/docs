Namespace publishes focused TypeScript SDKs for offchain management, mint preparation, and indexed onchain data. Choose the client that matches the operation your application performs.

SDK packages include:

<CardGroup cols={2}>
  <Card title="Offchain Manager" icon="cloud" href="/developer-guide/sdks/offchain-manager">
    Create, update, delete, and query gasless offchain subnames and records.
  </Card>
  <Card title="Mint Manager" icon="gauge" href="/developer-guide/sdks/mint-manager">
    Check eligibility and generate mint transaction parameters for Ethereum or L2 chains.
  </Card>
  <Card title="Indexer Manager" icon="database" href="/developer-guide/sdks/indexer-manager">
    Query indexed subnames and registry deployments from L2 chains.
  </Card>
  <Card title="Avatar" icon="image" href="/developer-guide/sdks/avatar">
    Upload and delete ENS avatar and header images with SIWE authentication.
  </Card>
</CardGroup>
