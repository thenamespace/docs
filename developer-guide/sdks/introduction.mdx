Namespace publishes focused TypeScript SDKs for offchain subnames, avatar uploads, and ENS interfaces in React. Choose the client that matches the operation your application performs.

SDK packages include:

<CardGroup cols={3}>
  <Card title="Offchain Manager" icon="cloud" href="/developer-guide/sdks/offchain-manager">
    Create, update, delete, and query gasless offchain subnames and records.
  </Card>
  <Card title="Avatar" icon="image" href="/developer-guide/sdks/avatar">
    Upload and delete ENS avatar and header images with SIWE authentication.
  </Card>
  <Card title="ENS Components" icon="puzzle-piece" href="/developer-guide/sdks/ens-components">
    Add React interfaces for ENS registration, record editing, and subname issuance.
  </Card>
</CardGroup>

## Deprecated SDKs

Mint Manager and Indexer Manager are deprecated. They keep working for onchain listings created on ENSv1 names.

<CardGroup cols={2}>
  <Card title="Mint Manager" icon="gauge" href="/developer-guide/sdks/mint-manager">
    Check eligibility and generate mint transactions for existing ENSv1 listings.
  </Card>
  <Card title="Indexer Manager" icon="database" href="/developer-guide/sdks/indexer-manager">
    Query indexed L2 subnames and registries for existing listings.
  </Card>
</CardGroup>
