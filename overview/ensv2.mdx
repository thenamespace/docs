[ENSv2](https://ens.domains/blog/post/ensv2-live-on-mainnet) is live on Ethereum mainnet. New `.eth` names are registered on ENSv2. Names registered before it, called ENSv1 names, keep resolving, and upgrading them to ENSv2 is optional.

Namespace works with both. Use this page to check what works with your name and what to do if you upgrade it.

## What works with each version

| Product | ENSv1 names | ENSv2 names |
| --- | --- | --- |
| [Offchain subnames](/user-guide/dev-portal) in the App, SDK, and API | Supported | Supported |
| [Onchain subnames](/user-guide/app) in the Namespace App | Existing listings keep working | Supported on Ethereum (L1) |
| [Resolvio](/user-guide/resolvio) | Supported | Supported |
| [ENS Widget](/user-guide/ens-widget) and [Subpages](/user-guide/subpages) | Supported | Not supported |
| [Mint Manager](/developer-guide/sdks/mint-manager), [Indexer Manager](/developer-guide/sdks/indexer-manager), and the Mint API | Deprecated, existing listings only | Not supported |

## You already use Namespace with an ENSv1 name

You don't need to do anything. Offchain subnames, onchain listings, and subnames you have already minted keep working, including L2 subnames on Base and Optimism.

### Set the resolver again after you upgrade

Upgrading a name to ENSv2 resets its resolver. If the name has offchain subnames, set the Namespace resolver again right after the upgrade so they keep resolving.

<Steps>
  <Step title="Open the name in the Namespace App">
    Connect the wallet that owns the name and open it in the [Namespace App](https://app.namespace.ninja). The app prompts you to upgrade ENSv1 names.
  </Step>

  <Step title="Upgrade to ENSv2">
    Follow the prompts and confirm the transactions in your wallet.
  </Step>

  <Step title="Configure the resolver">
    In **Offchain**, select the name and open **Resolution**. Click **Update resolver**, then **Configure**, and check that the status reads **Configured**. See [Configure the resolver](/user-guide/dev-portal#configure-the-resolver) for screenshots of each step.
  </Step>
</Steps>

### Onchain subnames stay on ENSv1

Onchain subnames don't migrate to ENSv2. A listing created on an ENSv1 name, and the subnames minted under it, stay on ENSv1.

<Warning>
  If your name has an active onchain listing, ask in the [Namespace Builders group](https://t.me/+5FAwyiKOTeswNTIy) before you upgrade it.
</Warning>

## You're starting with a new name

Names you register now, including through [Namespace search](/user-guide/app/search-register), are ENSv2 names. You can issue offchain or onchain subnames under them.

Offchain subnames are gasless and suit high-volume issuance. Manage them in the [Namespace App](/user-guide/dev-portal), or integrate them with the [SDK](/developer-guide/guide/create-offchain-subnames) or [API](/api-reference/introduction).

Onchain subnames are minted on Ethereum (L1). To offer them, [activate your name](/user-guide/app#activate-your-ens-name) in the Namespace App.
