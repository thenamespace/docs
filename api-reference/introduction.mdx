## Offchain Manager API

The Offchain Manager API allows you to create, update, delete, and retrieve offchain ENS subnames and their associated records by using the Namespace.

### Authentication

Some endpoints require authentication via API key using the `x-auth-token` header. You can generate API keys through the [Namespace App](https://app.namespace.ninja/offchain?activeTab=apiKeys).

```bash
x-auth-token: YOUR_API_KEY
```

## Universal usernames API

These routes connect a `.eth` name to a [username endpoint](/developer-guide/universal-usernames/endpoint-reference) your brand hosts. They use the same base URLs as the Offchain Manager API, but they don't accept API keys. Only the current exact owner of the parent name can call them, and the wallet signs every request.

### Authenticate as the owner

Both kinds of credential go in the `x-auth-token` header as `siwe:<base64(message)>.<base64(signature)>`, where the message is an [EIP-4361](https://eips.ethereum.org/EIPS/eip-4361) sign-in message, the signature is the wallet's hex signature string, and both are base64-encoded as UTF-8 text. The message `domain` is the API host, such as `offchain-manager.namespace.ninja`, or a Namespace App domain.

- Reads, such as getting the connection or validating an endpoint, take an unexpired sign-in session signed by the owner.
- Each change takes its own operation signature: a fresh message with a nonce from [`GET /api/v1/auth/nonce`](/api-reference/offchain-manager/universal-usernames/get-nonce), the statement `Authorize <action> for Universal Usernames on <parentName>`, an expiry at most 10 minutes after it was issued, and exactly one resource, `urn:namespace:uun:<parentNode>:<action>:<expectedRevision>`.

The actions are `save`, `activate`, `rotate-credential`, `pause`, `resume`, and `disconnect`. `chainId` is `1` on the production API and `11155111` on staging. A nonce expires 60 seconds after you request it and works once.

```ts
const message = createSiweMessage({
  domain: 'app.namespace.ninja',
  uri: 'https://app.namespace.ninja',
  address: owner.address,
  statement: `Authorize pause for Universal Usernames on ${parentName}`,
  version: '1',
  chainId: 1,
  nonce, // from GET /api/v1/auth/nonce
  issuedAt,
  expirationTime: new Date(issuedAt.getTime() + 5 * 60 * 1000),
  resources: [`urn:namespace:uun:${namehash(parentName)}:pause:${revision}`],
});
const signature = await owner.signMessage({ message });
const base64 = (text: string) => Buffer.from(text, 'utf8').toString('base64');
const token = `siwe:${base64(message)}.${base64(signature)}`;
```

The [Offchain Manager SDK](/developer-guide/sdks/offchain-manager/universal-usernames) builds and signs these messages for you.
