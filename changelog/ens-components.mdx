Release notes for [`@thenamespace/ens-components`](https://www.npmjs.com/package/@thenamespace/ens-components). Dates are npm publish dates. Prereleases on the `alpha` tag aren't listed separately; their changes are listed under the stable release that shipped them.

To move from 2.x to 3.x, follow [Upgrade to the latest version](/developer-guide/sdks/ens-components/upgrade).

<Update label="October 28, 2026" description="v3.0.0">
  - Breaking:
    - **Onchain flows default to ENSv2.** `version` on `EnsNameRegistrationForm`, `NameRenewForm`, `EnsRecordsForm`, `SubnameMintForm`, and the `useENSResolver` hook defaults to `2`. Pass `version={1}` to `SubnameMintForm` for parents on an old Namespace listing. ENSv1 registration and renewal are retired.
    - **`.eth` registration is paid in USDC or DAI.** In `onRegistrationSuccess`, `registrationCost` is the token amount, and `transactionFees` and `total` are both the ETH network fees.
    - **`TransactionPendingScreen` no longer takes a `message` prop.** `hash` is now optional, and a new `details` prop takes label and value rows.
  - Added:
    - **`NameRenewForm`**: renews a `.eth` name in one step, paid in USDC or DAI. Anyone can renew any name, and the owner keeps it.
    - **`SubnameRenewForm`**: renews a subname at the price set by the parent's owner, and warns when the subname would outlive its parent.
    - **`TransactionProgress` and `TransactionModal`**: the progress screen every form uses, exported for your own transactions.
    - **ENSv2 subname minting** in `SubnameMintForm`, through Namespace's ENSv2 activation contracts. The user picks ETH, USDC, or DAI on mainnet, or ETH or USDC on Sepolia.
    - **`resolver` prop** on `SubnameMintForm` for activations that don't set a resolver.
    - **`priceCurrency`** on the `SubnameMintForm` `onSuccess` payload.
    - ENSv2 helpers: `getEnsV2RegistrationDeployment`, `isEnsV2NameAvailable`, `getEnsV2Deployment`, `quoteEnsV2Mint`, `quoteEnsV2Payment`, `getEnsV2RenewalDeployment`, `getEnsV2RenewalTarget`, `getEnsV2RenewPrice`, and `quoteEnsV2Renewal`.
  - Changed:
    - ENSv2 runs on mainnet and Sepolia. Contract addresses come from `@thenamespace/addresses` 1.2.0.
    - ENSv2 registration gives each owner a PermissionedResolver, deployed with the name's records. Commitments resume after a page reload.
    - `EnsRecordsForm` finds the resolver through the ENSv2 Universal Resolver and writes to standard resolvers, PermissionedResolvers, and Namespace's SimplifiedResolver.
    - Registration and renewal send the `referrer` prop, falling back to Namespace's referrer address.
    - Wallets with EIP-5792 atomic batching confirm each step in one prompt. Other wallets get one transaction per call.
    - Forms show "Insufficient funds" and block the transaction when the wallet can't cover the token price or gas.
    - The subname mint fee estimate uses the effective gas price.
    - The package ships CommonJS bundles for `require` entries.
</Update>

<Update label="October 5, 2026" description="v2.2.0">
  - Added:
    - A **Custom** section in the records editor for arbitrary key and value text records.
  - Changed:
    - Every top-level form card is 500 px wide, set by `--ns-frame-width`.
    - Registration, subname minting, and offchain subname forms share one layout and no longer depend on host Bootstrap margins.
    - Visible hover states on buttons, and alerts without the left accent bar.
</Update>

<Update label="September 23, 2026" description="v2.1.0">
  - Fixed:
    - `SubnameMintForm` estimates the network fee when the wallet can't cover price and fee, then shows "Insufficient funds" and disables **Mint** instead of showing N/A.
    - `EnsNameRegistrationForm` checks `.eth` availability with the registrar instead of the registry, so expired names past their grace period show as available.
</Update>

<Update label="September 11, 2026" description="v2.0.0">
  - Breaking:
    - **New visual design.** Components adopt the Namespace Flows design system: a near-black accent derived from `--ns-ink` instead of blue, 10 px corners from `--ns-radius` instead of square ones, and DM Sans and DM Mono instead of Satoshi. Props, hooks, and exports are unchanged.
  - Added:
    - A token layer (`--ns-` variables). Older `--ns-color-*`, `--ns-blue-*`, and `--ns-alert-*` names still resolve as aliases.
    - `Tag` and `Identicon` atoms.
    - One availability status line for every name state in registration, subname minting, and offchain subname forms.
    - A "No records found" state with a clear-filter action in the records editor search.
  - Changed:
    - The stylesheet no longer forces a background on the host page's `html` element.
    - Forms use container queries, so they adapt inside narrow modals on desktop screens.
    - The records editor is 600 px wide.
</Update>
