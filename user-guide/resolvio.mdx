[Resolvio](https://www.resolvio.xyz/) is a universal ENS resolution API. One endpoint handles forward and reverse resolution, CCIP-Read (offchain subnames), bulk lookups, multichain coin types, and caching. No authentication or API key is required.

## Features

- Forward and reverse resolution
- CCIP-Read support for offchain subnames
- Bulk lookups for tables, leaderboards, and multi-row UI
- Built-in caching with controls
- Chain directory: look up any chain by name, no `coin_type` required
- Self-hostable: run your own instance
- No auth, no API keys
- MIT-licensed, open-source
