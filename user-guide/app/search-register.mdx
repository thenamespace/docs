Use [Namespace search](https://app.namespace.ninja/search) to find and register an ENS name such as `example.eth` or an available onchain subname such as `alice.brand.eth`.

## What you can register

| Result | What you receive | Registration terms |
| --- | --- | --- |
| ENS name | A second-level `.eth` name | Registration period and price follow ENS rules |
| Onchain subname | A name beneath an activated parent ENS name | Price, network, ownership, and expiry follow the parent's listing rules |

## Search for a name

<Steps>
  <Step title="Open Namespace search">
    Visit [app.namespace.ninja/search](https://app.namespace.ninja/search), connect your wallet, and enter the name you want.
  </Step>

  <Step title="Choose a result">
    Search results can include the exact `.eth` name and matching subnames from parent names activated on Namespace. Each subname shows its price or a **Free Mint** label.

    <img src="/assets/search-results.png" alt="Namespace search results with an ENS name and matching available subnames" width="563" />
  </Step>

  <Step title="Review the registration">
    Select the result you want and check the full name, owner, network, registration or mint price, estimated network fee, and total before continuing.
  </Step>

  <Step title="Confirm in your wallet">
    Continue from the registration dialog and approve the required wallet transaction. Wait for the transaction to confirm before using the name.
  </Step>
</Steps>

## Register an onchain subname

The registration dialog shows the parent name's configured mint price, estimated network fee, and total. Free listings show a **Free Mint** label.

<img src="/assets/register-subname.png" alt="Onchain subname registration dialog with the owner, price, network fee, and total" width="500" />

Onchain subname ownership and expiry on Ethereum Mainnet depend on the parent name's ENS fuse and listing configuration. On L2 chains, subnames can also use a registration period when the parent-name owner enables renting.

## Register an ENS name

For an available `.eth` name, choose the registration period and review the registration fee, estimated network fee, and total. Continue through the wallet prompts shown by the app.

<img src="/assets/register-name.png" alt="ENS name registration dialog with the registration period, fee, and total" width="500" />
