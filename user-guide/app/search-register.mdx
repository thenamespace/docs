Use [Namespace search](https://app.namespace.ninja/search) to register an ENS name such as `example.eth` or an available onchain subname such as `alice.brand.eth`. A `.eth` name takes two wallet transactions with a short wait between them. You can set up the name's profile during registration.

New `.eth` names you register through Namespace are ENSv2 names.

## Before you start

- A wallet connected to the [Namespace App](https://app.namespace.ninja).
- Enough of the payment token for the registration fee, plus ETH for network fees.

## What you can register

| Result | What you receive | Registration terms |
| --- | --- | --- |
| ENS name | A second-level `.eth` name | Registration period and price follow ENS rules |
| Onchain subname | A name beneath an activated parent ENS name | Price, network, ownership, and expiry follow the parent's listing rules |

## Register an ENS name

<Steps>
  <Step title="Search for a name">
    Open **Search and register** in the sidebar, or go to [app.namespace.ninja/search](https://app.namespace.ninja/search). Type the name you want in the search box.

    <Frame>
      <img src="/assets/register/search-name.png" alt="Register your Web3 identity page with an empty Search for a name to register field" />
    </Frame>
  </Step>

  <Step title="Check availability">
    The results list the `.eth` name first. An **AVAILABLE** status means you can register it. Below it, the list shows matching subnames from parent names activated on Namespace, each with its price and a **MINT** button.

    Select the `.eth` name to start registering it.

    <Frame>
      <img src="/assets/register/search-results.png" alt="Search results for onchin with onchin.eth marked Available and matching onchain subnames listed with prices and Mint buttons" />
    </Frame>
  </Step>

  <Step title="Choose the duration and payment token">
    The **Claim your Web3 identity** dialog shows the name and its expiry date. To change how long you register the name, pick a date with the calendar button or select **PICK BY YEARS**.

    Check the **Registration Fee**, **Est. network fees**, and **Total**. Use the token menu next to the total to choose what you pay with. The dialog also shows the approximate USD value.

    <Frame>
      <img src="/assets/register/registration-details.png" alt="Claim your Web3 identity dialog for onchin.eth with an expiry date, registration fee in USDC, estimated network fees in ETH, total with a token menu, Complete your profile, and Next" />
    </Frame>
  </Step>

  <Step title="Set up your profile">
    To add profile records to the name as part of registration, select **Complete your profile** before you continue. You can skip this and edit records after the name is registered.

    <Frame>
      <img src="/assets/register/complete-profile.png" alt="Complete your profile card with the text Make your ENS more discoverable and an arrow button" />
    </Frame>

    When you're ready, select **Next**.
  </Step>

  <Step title="Send the commitment transaction">
    The **ENS Registration Process** dialog lists three steps: **Commitment**, **Timer Started**, and **Complete Registration**. Under **Commitment**, select **Open Wallet** and approve the transaction in your wallet.

    After you approve it, the dialog shows **Transaction Sent** with a **View on Etherscan** link. Wait for the transaction to confirm.

    <Frame>
      <img src="/assets/register/commit-transaction.png" alt="ENS Registration Process dialog with the Commitment step open and an Open Wallet button" />
    </Frame>
  </Step>

  <Step title="Wait for the timer">
    Once the commitment confirms, a countdown starts. The wait helps protect your registration from front-running. Keep the dialog open until the timer finishes.

    <Frame>
      <img src="/assets/register/wait-timer.png" alt="Timer Started step showing a countdown with Commitment marked complete" />
    </Frame>
  </Step>

  <Step title="Complete the registration">
    Under **Complete Registration**, select **Open Wallet** and approve the second transaction. The name isn't registered until this transaction confirms. The dialog shows how many hours you have left to complete it.

    <Frame>
      <img src="/assets/register/complete-registration.png" alt="Complete Registration step with the Register Name message, time remaining to finish, and an Open Wallet button" />
    </Frame>
  </Step>

  <Step title="Confirm the name is registered">
    When the transaction confirms, the dialog marks the name **REGISTERED**. It shows the registration length and fee, the transaction fees, and when the name expires.

    Select **View Name** to open the name, **Register another** to search again, or **Great!** to close the dialog.

    <Frame>
      <img src="/assets/register/registered.png" alt="Registration complete dialog for onchin.eth marked Registered, with registration length, fee, transaction fees, expiry date, and Register another, View Name, and Great buttons" />
    </Frame>
  </Step>
</Steps>

## Register an onchain subname

Select **MINT** next to a subname in the search results. The registration dialog shows the parent name's configured mint price, estimated network fee, and total. Free listings show **Free** instead of a price.

<img src="/assets/register-subname.png" alt="Onchain subname registration dialog with the owner, price, network fee, and total" width="500" />

Onchain subname ownership and expiry on Ethereum Mainnet depend on the parent name's ENS fuse and listing configuration. On L2 chains, subnames can also use a registration period when the parent-name owner enables renting.
