Namespace provides TypeScript SDKs and hosted APIs for creating, querying, and resolving ENS subnames. Choose the interface that fits your runtime and how much infrastructure you want to manage.

## Available tools

| Tool | Use it to |
| --- | --- |
| Offchain Manager | Create, update, delete, and query gasless offchain subnames and records |
| Offchain API | Manage offchain subnames over HTTP |
| Resolvio API | Resolve ENS names, profiles, addresses, text records, and content hashes |

## Deprecated tools

These tools still work for onchain listings on ENSv1 names. Don't use them for new integrations.

| Tool | Reference |
| --- | --- |
| Mint Manager SDK | [Mint Manager](/developer-guide/sdks/mint-manager) |
| Indexer Manager SDK | [Indexer Manager](/developer-guide/sdks/indexer-manager) |

## Before you integrate

- Keep Namespace API keys in server-side environment variables.
- Decide whether your product needs operator-managed offchain records or onchain subnames on Ethereum.
- Use a testnet configuration during development.
- Handle unavailable labels, authentication failures, rate limiting, and resolver errors explicitly.
- Pin supported package versions and review the changelog before upgrading.
